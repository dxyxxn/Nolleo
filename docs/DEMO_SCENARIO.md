# 길동무 — 3분 시연 대본

> Pleos Connect Emulator 2.1.0 기준. 실제 SDK 가 되는 부분(차량 상태·주행 규제·좌석·TTS·NaviHelper 이벤트·근접 알림)은 실제로,
> 에뮬레이터가 못 하는 부분(차량 이동에 따른 남은 시간 감소, 마이크 입력)은 **시뮬레이션 여정 + 대본 응답**으로 채운다.
> 화면 오른쪽(또는 별도 창)에 logcat 을 함께 띄우면 "SDK 이벤트 → 모드 전환"이 한눈에 보인다.
> 기능 하나하나를 따로 확인하는 방법은 [`FEATURE_GUIDE.md`](FEATURE_GUIDE.md) 에 있다.

## 0. 녹화 전 준비 (영상 밖)

```bash
# 1) AVD 를 cold boot 로 켜고
adb devices
# 2) 설치 (처음 한 번)
adb install -r apk/Team-DonDoAYeon_길동무_release.apk
# 3) Virtual Console
adb forward tcp:8088 tcp:8088          # 브라우저: http://127.0.0.1:8088/
# 4) 로그 창 (선택)
adb logcat -v time -s Gildongmu/ModeArbiter:I Gildongmu/GameSession:I Gildongmu/Coordinator:I Gildongmu/NaviHelper:I Gildongmu/RestCare:I Gildongmu/AaosCar:I
```

앱에서 (제목 **"길동무" 길게 누르기 → DEV 디버그 패널**):

| 설정 | 값 | 이유 |
|---|---|---|
| 데모 모드 | **켜짐** | 판당 6문제, 운전자 기준값이 없으면 1.5초로 시드, 졸음 쿨다운을 1단계 20초·2단계 60초로 줄임(판단 규칙은 같음) |
| 여정 | **시뮬** | 남은 시간이 실제로 줄어드는 흐름 (실제 1분 = 여정 30분) |
| 응답 입력 | **대본 normal** | 마이크 없이도 답이 들어옴 (TTS 는 실제 Pleos 음성) |
| 위치 | 자동 | 시뮬 여정 경로를 따라 지역이 바뀜 (서울 → 경기 → 충북 …) |

Virtual Console 은 **Motion > Gear Selection = P** 로 시작. 첫 실행이면 권한 2개(차량 속도·차량 위치)를 허용해 둔다.

### 팁
- ④⑤를 짧게 보여 주려면 홈에서 동승자를 **혼자**로 둔다(운전자 차례만 이어짐). 동승자가 있으면 1~2판 걸린다.
- 2단계는 1단계 뒤 20초(데모 쿨다운)가 지난 **다음 느린 답**에서 걸린다. 사이에 길 안내 일시정지나 판 경계(판 첫 문제는 졸음 지표에서 제외)가 끼면 늦어지므로, 1단계 뒤 30초 안에 안 나오면 디버그 패널 **"2단계 시험 (다음 운전자 답 뒤)"** 를 누른다(로그 사유가 `디버그 시험` 으로 남음 — 영상에서 숨길 필요는 없다).
- ⑤의 쉬어 갈 곳은 그 순간 시뮬 위치 앞쪽의 휴게소·졸음쉼터다(디버그 패널 졸음 케어 칸 "지금 걸리면 권할 곳" 줄에 미리 보인다). 서울 → 부산 시뮬은 에뮬레이터 내비와 같은 길(영동선 → 중부내륙선)이라 용인졸음쉼터·용인휴게소·덕평휴게소·여주휴게소·충주휴게소·괴산휴게소… 순서다. 휴게소를 확실히 보이려면 **서울 → 전주**(출발 직후 기흥휴게소, 수유실·가족사랑 화장실)를 쓴다.
- 시뮬은 묻는 동안 멈췄다가, 수락하면 다시 달려 십여 초 안에 그 지점에 닿는다(도착). 그 전에 **Gear = P** 로 세워도 도착이다. 졸음쉼터라면 디버그 패널 "쉬어 가기 상태" 줄의 `geo fix <경도> <위도>` 로 `adb emu geo fix` 를 해서 FusedLocation 근접 알림으로 도착시킬 수도 있다(release 는 위치 관련 로그를 `<redacted>` 로 가림).
- ⑤에서 "아니요"로 거절하는 장면을 보이려면 디버그 패널 **오답/무응답** 대신 화면의 **괜찮아요** 를 누른다 → "알겠어요. 대신 다음 문제는 쉬운 걸로 갈게요."
- ②~④ 에서 마이크로 직접 답하려면 에뮬레이터 *Extended Controls > Microphone > Virtual microphone uses host audio input* 을 켜고 응답 입력을 **마이크**로 둔다("네"/"아니요"도 음성으로).
- 디버그 패널의 **정답 / 오답 / 무응답** 버튼으로 대본 대신 즉석에서 답을 넣을 수 있다(주행 규제 중에는 텍스트 입력만 막힘).
- 시연을 중간에 끊으려면 **일시정지 → 게임 끝내기**(정차 중에는 화면 게임 상단). 맞힌 문제가 있으면 "여기까지 했어요" 요약, 없으면 바로 홈으로 간다. 내비 경로는 그대로 남는다.

## 2. (선택) 실제 SDK 만으로 보여 주는 짧은 클립

| 클립 | 조작 | 기대 결과 |
|---|---|---|
| 실제 내비 경로 | 디버그 패널 여정 = **자동** → 홈에서 **서울 → 부산** → 출발 | 순정 내비가 경로를 띄움, 로그 `onRouteStarted raw duration=14820 distance=378000`, 길동무로 돌아오면 "도착까지 4시간 7분" |
| 내비에서 잡은 목적지 | 길동무를 켠 채 내비에서 목적지 검색(최근: 부산역) → **안내 시작** → 길동무 홈 확인 | 1초 안에 **"내비 목적지: 부산역 · 남은 시간 4시간 2분"** 카드가 생기고 선택됨(로그 `navi route detected`) → 출발하면 경로 요청 없이 그 남은 시간으로 플랜 생성. 내비에서 **안내 종료** → 카드가 사라지고 프리셋으로 |
| 경로 위 휴게소·졸음쉼터 (실제 내비 TBT) + 근접 알림 | `adb emu geo fix 127.10 37.40` → 디버그 패널 여정 = **자동** → **서울 → 부산** 출발 → 길동무로 돌아와 Gear D → 디버그 패널 **2단계 시험** | 디버그 패널 "경로 위: 용인졸음쉼터 18.1km, 용인휴게소 28.5km, 덕평휴게소 41.2km …"(TBT 구간 거리 누적) → 질문 "가는 길에 있는 용인졸음쉼터가 18킬로미터 앞이에요. 거기서 잠깐 쉬어 갈까요?" → 네 → `proximity alert registered` (내비 경로는 그대로) → `adb emu geo fix 127.138727 37.288616` → `rest stop arrived (위치가 쉼터 0m 안)` |
| 실제 위치로 지역 판정 | `adb emu geo fix 126.9780 37.5665` (서울 시청, 경도 먼저) → 디버그 패널 위치 소스 확인 | 로그 `Gildongmu/Location: region=seoul via FusedLocation` — 내비 주소 폴백(경기) 대신 실제 FusedLocation 값으로 지역 퀴즈 지역이 정해짐. 시뮬 여정 중에는 시뮬 경로가 우선 |
| 주행 규제 | 세션 없이 Gear = D | 홈이 "주행 중에는 여정 설정을 할 수 없어요"로 바뀜 (`NO_SETUP` 비트) |
| 3분할(내비와 나란히) | 길동무가 앱 영역 전체일 때 화면 오른쪽 끝 **⋮** 창 막대를 가운데로 끌기 | 길동무가 왼쪽 창으로 줄어든 직후 스스로 **맨 오른쪽**으로 이동 → Driving view \| 내비 \| 길동무 (로그 `Gildongmu/Window: 3분할 …`). 세로 1창 레이아웃도 잘리지 않음. 가운데 막대를 탭해 직접 자리를 바꾸면 그대로 둔다 |
| 백그라운드 | 하단 독의 내비 아이콘 → 다시 길동무 아이콘 | 발화가 끊겼으면 "잠시 멈췄어요 + 계속", 계속을 누르면 같은 문제부터 |

## 3. 녹화 전 체크리스트
- [ ] AVD cold boot, `adb devices` 에 emulator 표시
- [ ] `adb forward tcp:8088 tcp:8088` 후 Virtual Console 접속, 기어 P
- [ ] 권한 2개 허용(차량 속도·차량 위치)
- [ ] 디버그 패널: 데모 모드 켜짐 · 여정 시뮬 · 응답 입력 대본 normal
- [ ] (④ 전에) 응답 입력 대본 sleepy 로 바꿀 위치 확인 (체크 ✓ 가 붙은 버튼에 따라 버튼 위치가 조금씩 달라진다)
- [ ] 시스템 볼륨이 켜져 있는지(Pleos TTS 음성이 영상에 들어가야 함)
- [ ] 이전 세션이 남아 있으면 홈의 "새로 시작"
- [ ] 홈 목적지가 **서울 → 부산** 프리셋으로 선택돼 있는지 — 순정 내비에 길 안내가 켜져 있으면 맨 위에 "내비 목적지" 카드가 보인다(여정=시뮬이면 자동 선택하지 않음). 카드를 고르면 실제 내비 여정이라 남은 시간이 줄지 않으므로 ①에서는 프리셋을 쓴다
- [ ] 홈의 판 간격이 **여유 있게**인지 (마지막으로 출발한 간격이 저장되므로, 다른 간격으로 시험했다면 되돌려 둔다)
- [ ] 운전자 기준값이 이전 시험으로 커져 있으면 디버그 패널 **운전자 기준값 초기화**(데모 모드는 1.5초로 다시 시드)
