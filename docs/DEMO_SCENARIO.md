# 놀레오 — 3분 시연 대본

> Pleos Connect Emulator 2.1.0 기준. 실제 SDK 가 되는 부분(차량 상태·주행 규제·좌석·TTS·NaviHelper 이벤트·근접 알림)은 실제로,
> 에뮬레이터가 못 하는 부분(차량 이동에 따른 남은 시간 감소, 마이크 입력)은 **시뮬레이션 여정 + 대본 응답**으로 채운다.
> 화면 오른쪽(또는 별도 창)에 logcat 을 함께 띄우면 "SDK 이벤트 → 모드 전환"이 한눈에 보인다.
> 기능 하나하나를 따로 확인하는 방법은 [`FEATURE_GUIDE.md`](FEATURE_GUIDE.md) 에 있다.
> 화면은 주간 테마(연회색 바탕·흰 카드·검정 글, 노란 주 버튼)로 찍는 것을 기준으로 했다. 에뮬레이터가 야간 모드면 `adb shell cmd uimode night no` 로 되돌린다.

## 0. 녹화 전 준비 (영상 밖)

```bash
# 1) AVD 를 cold boot 로 켜고
adb devices
# 2) 설치 (처음 한 번)
adb install -r apk/돈도아연_놀레오_release.apk
# 3) Virtual Console
adb forward tcp:8088 tcp:8088          # 브라우저: http://127.0.0.1:8088/
# 4) 로그 창 (선택)
adb logcat -v time -s Nolleo/ModeArbiter:I Nolleo/GameSession:I Nolleo/Coordinator:I Nolleo/NaviHelper:I Nolleo/RestCare:I Nolleo/AaosCar:I Nolleo/IdiomQuiz:I Nolleo/RegionQuiz:I Nolleo/WordQuiz:I Nolleo/Location:I Nolleo/Window:I
# 5) 녹화 — 에뮬레이터 자체 녹화(소리 포함, 파일은 PC 에 바로 생김). 경로는 / 로 쓴다
adb emu screenrecord start --time-limit 240 C:/녹화/nolleo_demo.webm
adb emu screenrecord stop          # 일찍 끝낼 때
```

녹화 방법(11/8 확인): 위 5) 의 에뮬레이터 자체 녹화는 화면 2560×1440(VP9) + **소리(Vorbis)** 를 함께 담아 TTS 음성까지 들어간다. Android Studio 의 Record Screen 과 같은 `adb shell screenrecord` 는 화면만(H.264 mp4, 소리 없음) 담기고 기본 3분까지라(`--time-limit 0` 이면 제한 없음) 소리가 필요하면 쓰지 않는다. 마이크 응답을 쓸 때 사람 목소리는 호스트 마이크로 들어가므로 녹음 여부는 따로 확인해야 한다(확인 못 함).

앱에서 (왼쪽 위 로고·제목 **"Nolleo" 길게 누르기 → DEV 디버그 패널**):

| 설정 | 값 | 이유 |
|---|---|---|
| 데모 모드 | **켜짐** | 판당 6문제, 운전자 기준값이 없으면 1.5초로 시드, 졸음 쿨다운을 1단계 20초·2단계 60초로 줄임(판단 규칙은 같음) |
| 여정 | **시뮬** + 시뮬 경로 **서울 → 부산** | 남은 시간이 실제로 줄어드는 흐름 (실제 1분 = 여정 30분). 시뮬 경로는 여정 칸의 버튼으로 고르고, 홈 `목적지` 맨 위(현재 경로 자리)에 `서울 → 부산 · 시뮬 여정 · 부산역`으로 보인다(11/8 부터 홈에 프리셋이 없다) |
| 응답 입력 | **대본 normal** | 마이크 없이도 답이 들어옴 (TTS 는 실제 Pleos 음성) |
| 위치 | 자동 | 시뮬 여정 경로를 따라 지역이 바뀜 (서울 → 경기 → 충북 …) |

Virtual Console 은 **Motion > Gear Selection = P** 로 시작. 첫 실행이면 권한 2개(차량 속도·차량 위치)를 허용해 둔다.

| ⑦ | 2:25–2:45 | Virtual Console **Gear = D** | 화면 게임이 즉시 닫히고(사자성어를 읽던 중이면 바로 멈춤) TTS **"아빠, 잘 쉬셨나요? 다시 출발해요!"** → 졸음 지표·난이도 초기화 → 다음 판 | AAOS Car API, TTS |
| ⑧ | 2:45–3:00 | 디버그 패널 → **남은 5분으로** → 요약이 뜨면 Virtual Console **Gear = P** | "곧 도착이에요! 오늘의 1등은 …" → 주행 중이라 **짧은 요약**(`도착했어요` · `N번 맞혔어요 · 1등 아빠` · `차를 세우면 오늘의 기록을 모두 보여 드려요` · 처음으로 — 운전 중 화면은 3줄) → 기어 P 로 세우면 **전체 요약**(오늘의 기록·가족 점수 카드, 지나온 지역 칩, "휴게소·졸음쉼터에서 쉬어 가기를 1번 권했어요") | 시뮬 여정, CarUxRestrictions |

### 팁
- ④⑤를 짧게 보여 주려면 홈에서 동승자를 **혼자**로 둔다(운전자 차례만 이어짐). 동승자가 있으면 1~2판 걸린다.
- 2단계는 1단계 뒤 20초(데모 쿨다운)가 지난 **다음 느린 답**에서 걸린다. 사이에 길 안내 일시정지나 판 경계(판 첫 문제는 졸음 지표에서 제외)가 끼면 늦어지므로, 1단계 뒤 30초 안에 안 나오면 디버그 패널 **"2단계 시험 (다음 운전자 답 뒤)"** 를 누른다(로그 사유가 `디버그 시험` 으로 남음 — 영상에서 숨길 필요는 없다).
- ⑤의 쉬어 갈 곳은 그 순간 시뮬 위치 앞쪽의 휴게소·졸음쉼터다(디버그 패널 졸음 케어 칸 "지금 걸리면 권할 곳" 줄에 미리 보인다). 서울 → 부산 시뮬은 에뮬레이터 내비와 같은 길(영동선 → 중부내륙선)이라 용인졸음쉼터·용인휴게소·덕평휴게소·여주휴게소·충주휴게소·괴산휴게소… 순서다. 휴게소를 확실히 보이려면 **서울 → 전주**(출발 직후 기흥휴게소, 수유실·가족사랑 화장실)를 쓴다.
- 시뮬은 묻는 동안 멈췄다가, 수락하면 다시 달려 십여 초 안에 그 지점에 닿는다(도착). 그 전에 **Gear = P** 로 세워도 도착이다. 졸음쉼터라면 디버그 패널 "쉬어 가기 상태" 줄의 `geo fix <경도> <위도>` 로 `adb emu geo fix` 를 해서 FusedLocation 근접 알림으로 도착시킬 수도 있다(release 는 위치 관련 로그를 `<redacted>` 로 가림).
- ⑤에서 "아니요"로 거절하는 장면을 보이려면 디버그 패널 **오답/무응답** 대신 화면의 **괜찮아요** 를 누른다 → "알겠어요. 대신 다음 문제는 쉬운 걸로 갈게요."
- ②~④ 에서 마이크로 직접 답하려면 에뮬레이터 *Extended Controls > Microphone > Virtual microphone uses host audio input* 을 켜고 응답 입력을 **마이크**로 둔다("네"/"아니요"도 음성으로).
- 디버그 패널의 **정답 / 오답 / 무응답** 버튼으로 대본 대신 즉석에서 답을 넣을 수 있다(주행 규제 중에는 텍스트 입력만 막힘).
- ⑥의 사자성어는 고른 뒤 한자 풀이를 적어도 10초 보여 주고(유래가 길면 다 읽고 2.5초 뒤) 저절로 다음 문제로 넘어간다. 30초 구간이라 한 문제면 충분하고, 시간이 빠듯하면 **다음 문제**로 건너뛴다. 유래 읽기까지 보이려면 유래가 있는 문제(약 5문제 중 1문제)가 나올 때까지 넘긴다.
- 시연을 중간에 끊으려면 **일시정지 → 게임 끝내기**(정차 중에는 게임 목록 머리 줄 — 게임을 열었으면 **← 목록**으로 나와서). 맞힌 문제가 있으면 "여기까지 했어요" 요약, 없으면 바로 홈으로 간다. 내비 경로는 그대로 남는다.

## 2. (선택) 실제 SDK 만으로 보여 주는 짧은 클립

| 클립 | 조작 | 기대 결과 |
|---|---|---|
| 내비 최근 목적지로 출발 | 디버그 패널 여정 = **자동**, 내비 길 안내 없음 → 홈 최근 목적지 **부산역**(`약 4시간 6분` — 내비 `requestTrip` 예상 시간) → 출발 | 순정 내비가 앞으로 나와 부산역 길 안내 시작(로그 `requestRoute`, `onRouteStarted raw duration=14820 distance=378000`), 놀레오로 돌아오면 "도착까지 4시간 7분" (11/8 확인) |
| 내비에서 잡은 목적지 | 놀레오를 켠 채 내비에서 목적지 검색 → **안내 시작** → 놀레오 홈 확인 | 홈 `목적지` 맨 위에 **"현재 경로: 부산역 · 내비 길 안내 그대로"** 줄(오른쪽에 남은 시간)이 생기고 선택됨(로그 `current route available → 홈에서 현재 경로`), 최근 목적지 줄은 숨겨짐 → 출발하면 경로 요청 없이 그 남은 시간으로 플랜 생성. 내비에서 **안내 종료** → 최근 목적지·`목적지 없이`로 돌아옴 |
| 목적지 없이 | 홈 `목적지 없이`의 **30분** 칸 → 출발 → Gear = D → 디버그 패널 **남은 5분으로** | 미리보기 `30분 → 1판 (판당 약 6분)`, 상단 `남은 시간 29분`, 요약 `시간이 다 됐어요 · 목적지 없이 30분` (11/8 확인) |
| 경로 위 휴게소·졸음쉼터 (실제 내비 TBT) + 근접 알림 | `adb emu geo fix 127.10 37.40` → 디버그 패널 여정 = **자동** → 최근 목적지 **부산역** 출발 → 놀레오로 돌아와 Gear D → 디버그 패널 **2단계 시험** | 디버그 패널 "경로 위: 용인졸음쉼터 18.1km, 용인휴게소 28.5km, 덕평휴게소 41.2km …"(TBT 구간 거리 누적) → 질문 "가는 길에 있는 용인졸음쉼터가 18킬로미터 앞이에요. 거기서 잠깐 쉬어 갈까요?" → 네 → `proximity alert registered` (내비 경로는 그대로) → `adb emu geo fix 127.138727 37.288616` → `rest stop arrived (위치가 쉼터 0m 안)` |
| 실제 위치로 지역 판정 | `adb emu geo fix 126.9780 37.5665` (서울 시청, 경도 먼저) → 디버그 패널 위치 소스 확인 | 로그 `Nolleo/Location: region=seoul via FusedLocation` — 내비 주소 폴백(경기) 대신 실제 FusedLocation 값으로 지역 퀴즈 지역이 정해짐. 시뮬 여정 중에는 시뮬 경로가 우선 |
| 정차 중 지역 퀴즈 · 끝말잇기 | 출발 후 Gear = P → 게임 목록에서 **지역 퀴즈** / **끝말잇기** 의 **시작하기** | 지역 퀴즈: `지금 지나는 곳 · ○○` 문제와 보기, 고르면 힌트까지 읽음(시/도는 FusedLocation·시뮬 위치). 끝말잇기: `'고래' 다음에 이어질 말은?` 보기 4개 중 하나만 이어짐, 고르면 `고래 → 내복` + 두음법칙 안내. 둘 다 음성 판 점수와 따로 |
| 주행 규제 | 세션 없이 Gear = D | 홈이 "주행 중에는 여정 설정을 할 수 없어요"로 바뀜 (`NO_SETUP` 비트) |
| 3분할(내비와 나란히) | 놀레오가 앱 영역 전체일 때 화면 오른쪽 끝 **⋮** 창 막대를 가운데로 끌기 | 놀레오가 왼쪽 창으로 줄어든 직후 스스로 **맨 오른쪽**으로 이동 → Driving view \| 내비 \| 놀레오 (로그 `Nolleo/Window: 3분할 …`). 좁은 창 레이아웃도 잘리지 않음. 가운데 막대를 탭해 직접 자리를 바꾸면 그대로 둔다 |
| 백그라운드 | 하단 독의 내비 아이콘 → 다시 놀레오 아이콘 | 발화가 끊겼으면 "잠시 멈췄어요 + 계속", 계속을 누르면 같은 문제부터 |

## 3. 녹화 전 체크리스트
- [ ] AVD cold boot, `adb devices` 에 emulator 표시
- [ ] `adb forward tcp:8088 tcp:8088` 후 Virtual Console 접속, 기어 P
- [ ] 권한 2개 허용(차량 속도·차량 위치)
- [ ] 디버그 패널: 데모 모드 켜짐 · 여정 시뮬 · 시뮬 경로 서울 → 부산 ✓ · 응답 입력 대본 normal
- [ ] (④ 전에) 응답 입력 대본 sleepy 로 바꿀 위치 확인 (체크 ✓ 가 붙은 버튼에 따라 버튼 위치가 조금씩 달라진다)
- [ ] 시스템 볼륨이 켜져 있는지(Pleos TTS 음성이 영상에 들어가야 함)
- [ ] 주간 테마인지(`adb shell cmd uimode night` → `Night mode: no`), 하단 독에 놀레오 아이콘(차콜 바탕에 노란 언덕 길과 웃는 해)이 보이는지 — 같은 아이콘이 둘이면 예전 빌드를 지운다
- [ ] 이전 세션이 남아 있으면 홈의 "새로 시작"
- [ ] 홈 목적지 맨 위가 **서울 → 부산 · 시뮬 여정 · 부산역** 이고 선택돼 있는지 — 여정=시뮬이면 실제 내비 줄(현재 경로·최근 목적지)은 숨기고 시뮬 경로를 고른다. `목적지 없이`를 골라 두었으면 시뮬 경로 줄을 다시 누른다(실제 내비·시간 여정은 에뮬레이터에서 남은 시간이 줄지 않거나 실제 시간으로 흐른다)
- [ ] 홈의 판 간격이 **여유 있게**인지 (마지막으로 출발한 간격이 저장되므로, 다른 간격으로 시험했다면 되돌려 둔다)
- [ ] 운전자 기준값이 이전 시험으로 커져 있으면 디버그 패널 **운전자 기준값 초기화**(데모 모드는 1.5초로 다시 시드). 데모 모드 세션은 기준값을 저장하지 않으므로, 남아 있는 값은 데모가 아닌 세션이 남긴 것이다
