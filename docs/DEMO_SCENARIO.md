# 놀레오 — 시연 영상 시나리오 (편집본 약 3분)

> 영상은 한 번에 이어 찍지 않는다. **장면(클립)마다 따로 찍고 편집으로 이어 붙여** 약 3분으로 만든다(11/8 결정). 기다리는 구간은 잘라 내고, 디버그 패널을 누르는 장면도 잘라 낸다.
> Pleos Connect Emulator 2.1.0 기준. 실제 SDK 가 되는 부분(차량 상태·주행 규제·좌석·TTS·NaviHelper 최근 목적지·길 안내·TBT·근접 알림)은 실제로,
> 에뮬레이터가 못 하는 부분(차량 이동에 따른 남은 시간 감소, 마이크 입력)은 **시뮬레이션 여정 + 대본 응답**으로 채우고, 영상에 그렇다고 자막으로 밝힌다.
> 기능 하나하나를 확인하는 방법은 [`FEATURE_GUIDE.md`](FEATURE_GUIDE.md) 에 있다. 아래 클립은 모두 11/8 release 빌드로 에뮬레이터에서 찍어 본 것이다(팀원용 영상·리허설 — 각 클립의 "확인" 줄).

## 0. 녹화 준비 (영상 밖)

```bash
# 1) AVD 를 cold boot 로 켜고
adb devices
# 2) 설치 (처음 한 번)
adb install -r apk/돈도아연_놀레오_release.apk
# 3) Virtual Console
adb forward tcp:8088 tcp:8088          # 브라우저: http://127.0.0.1:8088/
# 4) 로그 창 (선택 — 편집 때 옆에 붙일 때)
adb logcat -v time -s Nolleo/ModeArbiter:I Nolleo/GameSession:I Nolleo/Coordinator:I Nolleo/NaviHelper:I Nolleo/RestCare:I Nolleo/AaosCar:I Nolleo/IdiomQuiz:I Nolleo/RegionQuiz:I Nolleo/WordChain:I Nolleo/Location:I Nolleo/Window:I
# 5) 녹화 — 에뮬레이터 자체 녹화(소리 포함, 파일은 PC 에 바로 생김). 경로는 / 로 쓴다. 클립마다 파일 하나
adb emu screenrecord start --time-limit 600 C:/녹화/clipA_home.webm
adb emu screenrecord stop
```

녹화 방법(11/8 확인): 에뮬레이터 자체 녹화는 화면 2560×1440(VP9) + **소리(Vorbis)** 를 함께 담아 TTS 음성까지 들어간다(`--size 1920x1080 --bit-rate 5M` 을 주면 작게). Android Studio 의 Record Screen 과 같은 `adb shell screenrecord` 는 화면만(H.264 mp4, 소리 없음) 담기므로 쓰지 않는다. 마이크 응답을 쓸 때 사람 목소리가 녹음되는지는 확인 못 함.

디버그 패널: 왼쪽 위 로고·제목 **"Nolleo" 길게 누르기**. 기어(P/D)는 Virtual Console **Motion > Gear Selection**(화면 왼쪽 계기판의 P R N D 로 보인다). 첫 실행이면 권한 2개(차량 속도·차량 위치)를 허용해 둔다.

## 2. 촬영 목록 (클립별)

각 클립은 [클립별 설정](#클립별-설정)으로 맞춘 뒤 녹화를 시작한다. "쓸 구간"은 편집에서 남길 부분이다.

### 클립 A — 홈 (원본 약 1분 → 18초)
1. 홈(기어 P, 여정 자동, 내비 길 안내 없음) — `목적지`에 최근 목적지 3곳과 오른쪽 예상 시간(예: `더현대서울 · 약 33분`, `부산역 · 약 3시간 59분`), 맨 아래 `목적지 없이` + 시간 막대 `30분 · 1시간 · 1시간 반 · 2시간`.
2. **목적지 없이**의 시간 칸 두어 번 → 미리보기가 그 시간에 맞춰 바뀐다(예: `30분 → 1판 (판당 약 6분)`).
3. 최근 목적지 **부산역** → 미리보기가 내비 예상 시간으로 바뀐다(`3시간 59분 → N판 (판당 약 10분)` · `판 사이 약 N분 쉬어요`).
4. `함께` 아래 "좌석 센서가 동승자 3명을 감지했어요" + **3명으로** → 다시 **1명**(에뮬레이터는 착좌 값이 고정 — 센서를 쓴다는 것만 보인다).
5. 게임 **랜덤**(판 구성 대신 `판마다 무엇이 나올지는 시작해야 알아요`) → **번갈아**(`1판 지역 퀴즈 · 2판 끝말잇기 …`), 간격 **여유 있게 ↔ 자주**(판 수가 바뀜).
- 쓸 구간: 1(3초) · 3(4초) · 4(4초) · 5(6초).
- 주의: 목적지를 바꾸면 미리보기 줄 수(쉬는 시간 줄 유무)가 달라져 아래 선택 막대가 조금 움직인다 — 화면을 보고 누른다.
- 확인: 팀원용 영상 2차 01(11/8).

### 클립 B — 최근 목적지로 출발 → 놀레오가 다시 앞으로 (원본 약 30초 → 18초)
1. 홈에서 최근 목적지 **더현대서울**(가까워서 예상 시간이 짧다) → **출발**.
2. 순정 내비가 앱 영역 전체를 덮고 경로를 보여 준다 → 약 7초 뒤 길 안내가 시작되면 **놀레오가 스스로 다시 앞으로**(정차 중 게임 목록, 칩 `도착까지 33분`).
- 쓸 구간: 1~2 전부(기다리는 3~4초는 2배속).
- 찍은 뒤(영상 밖): 놀레오 **게임 끝내기** → 하단 독의 내비 → **안내 종료**(놀레오는 운전자의 길 안내를 끄지 않는다).
- 3분할로 미리 나눠 두면 내비가 가운데 창에서만 안내해 "다시 앞으로"가 보이지 않는다 — 앱 영역 전체 창에서 찍는다.
- 확인: 팀원용 영상 2차 07, WORK_STATUS 1.23.

### 클립 C — 주행 중 지역 퀴즈 · 길 안내 자동 일시정지 (원본 약 2분 → 30초)
1. 홈 맨 위 `서울 → 부산 · 시뮬 여정 · 부산역` → **출발** → 정차 중 게임 목록.
2. 기어 **D** → 0.1초 안에 음성 모드. TTS "1번째 판! 지역 퀴즈… 지금은 서울특별시예요! 아빠 차례예요!" → 대본 답 → "딩동댕!" → 조수석 차례.
3. 시뮬 경로가 스스로 내는 분기점 안내(서울 → 부산 45분 지점 — 기어 D 뒤 약 1분 30초)를 기다린다 → `길 안내 후 이어서 할게요 / 분기점·회전 안내 구간이에요` → 약 11초 뒤 같은 문제부터 다시. 기다리기 싫으면 디버그 패널 **TBT 분기점 300m**(패널 장면은 잘라 낸다).
- 쓸 구간: 2(문제 1~2개, 17초) · 3(멈춤 → 다시, 13초).
- 확인: 팀원용 영상 2차 02, 리허설(11/8).

### 클립 D — 주행 중 가족 끝말잇기 (원본 1~2분 → 20초)
1. 출발 → 기어 **D** → "1번째 판! 끝말잇기를 시작할게요! 제가 먼저 할게요." → "저는 '우산' 할게요!" → (2초) → "아빠 차례예요! '산'으로 시작하는 말!" → 아빠 → "조수석 차례예요! '…'로 시작하는 말!" → 조수석 (11/11 — 놀레오도 한 차례, 누구 차례를 먼저 말함).
2. 문제 카드 맨 위 낱말 줄(`… 차선 → 선반 → 반지 → 지난주` — 이을 말 `지난주` 칸이 크게 강조), `'주'로 시작하는 말`, 듣는 동안 `8 초 안에 말해요`(1초마다 줄고 3초부터 빨강, 말을 시작하면 사라짐), 다음 판 `'리'나 '이'로 시작하는 말`(두음법칙).
3. 답한 뒤에는 칭찬 + 2초 동안 `조수석: 선반 → '선반' 성공` 판정 줄이 보이고, 다음 사람 차례에는 사라진다(11/11).
- 쓸 구간: 낱말이 3~4개 쌓인 뒤의 한 차례(남은 초가 보이는 순간 포함) + 두음법칙 안내.
- 주의: 대본 답이 잇기 어려운 낱말(예: `레크리에이션` → '션')을 고르면 놀레오가 "제가 졌어요"로 판을 일찍 끝낸다(규칙대로). 낱말 줄이 짧으면 새로 출발해 다시 찍는다.
- 이어서 기어 **P** 로 세우면 클립 F2(정차 끝말잇기)를 같은 세션에서 찍을 수 있다.
- 확인: 팀원용 영상 2차 03·08.

### 클립 E — 졸음 케어 1단계 → 2단계 → 경로 위 휴게소 (원본 약 3분 40초 → 40초)
설정이 중요하다: **출발 전에** 응답 입력 **대본 sleepy**, 함께 **혼자**(운전자 차례만 이어짐), 간격 **쉬지 않고**(판이 쉬지 않고 이어져 졸음 지표가 끊기지 않음), 디버그 패널 **운전자 기준값 초기화**.
1. 출발 → 기어 **D**. 운전자 응답이 2초 → 3.5 → 4.5 → 6초로 느려진다(판 첫 문제·일시정지 직후 답은 지표에서 뺀다).
2. **1단계**(기어 D 뒤 약 55초): 노란 안내 카드 "잠깐 쉬어 갈까요? 반응이 조금 느려졌어요" + TTS "아빠, 운전 오래 하셨죠? 다음 문제는 조금 쉬운 걸로 가 볼게요." → 난이도 상한이 내려간다.
3. 사이에 시뮬 경로의 분기점 안내로 한 번 멈출 수 있다(서울 → 전주 40분 지점) — 잘라 낸다.
4. **2단계**(기어 D 뒤 약 2분 25초, 사유 "15분 안에 1단계 두 번"): TTS "아빠, 반응이 계속 느려졌어요. 가는 길에 있는 ○○휴게소가 N킬로미터 앞이에요. …(편의시설)… 거기서 잠깐 쉬어 갈까요? 말로 '네' 또는 '괜찮아요'라고 해 주세요." + 카드에 편의시설·대표 음식 → 문제 카드 자리를 덮는 노란 안내 화면(큰 제목·말하는 중/듣는 중, 그 아래 여백 가운데에 큰 **쉬어 가기**/**괜찮아요**) → 대본 "네" → "좋아요. ○○휴게소에서 쉬어 가요. 도착할 때까지 게임은 쉴게요." → 같은 자리 `○○휴게소로 가는 중이에요 · 남은 거리 …`.
5. 시뮬 여정이 쉼터에 닿으면(수락 뒤 약 30초) "○○휴게소에 도착했어요. 차를 세우고 충분히 쉬었다 가요." → `○○휴게소에 도착했어요` 화면이 기어 P 까지 그대로(문제가 다시 보이지 않음 — 11/11 고침).
6. 기어 **P** → 정차 화면 게임 + `○○휴게소에서 쉬는 중 · 충분히 쉬었다 가요` → (여기서 클립 F1) → 기어 **D** → TTS "아빠, 잘 쉬셨나요? 다시 출발해요!" → 졸음 지표·난이도 초기화 → 다음 판이 바로 시작(쉬러 갈 때 판이 진행 중이었으므로 — 11/11).
- 쓸 구간: 1단계 카드·TTS(10초) · 2단계 안내 화면·질문(15초) · 가는 중 → 도착(8초) · 주차 화면(3초) · 다시 출발 인사(4초).
- 쉬어 갈 곳은 그 순간 시뮬 위치 앞쪽이다. 11/8 시험에서는 **정안알밤휴게소 19.3 km**(이 흐름), 출발 직후에 걸리면 기흥휴게소(수유실·가족사랑 화장실·제주고사리육개장 — 디버그 패널 졸음 케어 칸 "지금 걸리면 권할 곳"에 미리 보인다).
- 2단계가 늦으면 디버그 패널 **2단계 시험 (다음 운전자 답 뒤)**(패널 장면은 잘라 낸다 — 다음 답 3초 뒤에 걸림, 11/8 리허설). 거절 장면이 필요하면 응답 입력을 **직접 입력**으로 두고(대본이 "네"라고 하지 않게) 듣는 중에 화면의 **괜찮아요** → "알겠어요. 대신 다음 문제는 쉬운 걸로 갈게요." → 안내가 문제 카드 아래 띠로 15초(이때 띠의 **괜찮아요**를 누르면 띠가 바로 닫힌다).
- 확인: 11/8 시험 촬영(1단계 55초 · 2단계 2분 24초 · 수락 14초 뒤 · 도착 34초 뒤 · 다시 출발 뒤 바로 3판).

### 클립 F — 정차 중 화면 게임 (원본 약 1분 30초 → 15초)
- F1 (클립 E 의 쉼터 정차 중): **사자성어 → 시작하기** → 뜻을 읽어 줌 → 정답을 터치 → `정답이에요 · +10점` + 한자 4칸 훈·음(예: 桃 `복숭아 도`) + 정답·(있으면) 유래 읽기. 휴게소 이름 줄 때문에 보기가 조금 아래에 있다.
- F2 (클립 D 세션에서 기어 P, 대본 normal · 1명): **끝말잇기 → 시작하기** → 놀레오·아빠·조수석이 **말로** 잇는다(`무료입장 → 장애아 → 아래쪽 → 쪽파`), 남은 초·점수 칩 → **← 목록**.
- (여유가 있으면) **지역 퀴즈**: `지금 지나는 곳 · ○○` 문제 → 정답 → 힌트 읽기.
- 쓸 구간: F1 고른 뒤 한자 풀이(7초), F2 낱말 줄이 이어지는 한 차례(6초).
- 확인: 팀원용 영상 2차 05.

### 클립 G — 도착 요약 (원본 약 40초 → 14초)
1. 점수가 쌓인 세션(C 또는 D)에서 기어 **D** → 디버그 패널 **남은 5분으로**(패널 장면은 잘라 낸다).
2. "곧 도착이에요! …" → 주행 중이라 **짧은 요약**(`도착했어요` · `N번 맞혔어요 · 1등 아빠` · `차를 세우면 오늘의 기록을 모두 보여 드려요` · 처음으로).
3. 기어 **P** → **전체 요약**(오늘의 기록·가족 점수·지나온 지역 칩, 클립 E 세션이면 "휴게소·졸음쉼터에서 쉬어 가기를 1번 권했어요").
- 확인: 팀원용 영상 2차 06, 리허설(11/8).

### 클립 H — 야간 · 3분할 (원본 약 1분 → 8초)
1. 주행 중 음성 화면(끝말잇기) → `adb shell cmd uimode night yes` → 바로 어두운 색.
2. 기어 **P** → 화면 오른쪽 끝 **⋮** 창 막대를 가운데로 끌어 3분할(Driving view · 내비 · 놀레오) → 좁은 창 게임 목록 / 좁은 창 정차 끝말잇기.
3. 찍은 뒤 `adb shell cmd uimode night no`.
- 확인: 팀원용 영상 2차 08.

### 팁
- 디버그 패널의 **정답 / 오답 / 무응답** 버튼으로 대본 대신 즉석에서 답을 넣을 수 있다(주행 규제 중에는 텍스트 입력만 막힘).
- 마이크로 직접 답하려면 에뮬레이터 *Extended Controls > Microphone > Virtual microphone uses host audio input* 을 켜고 응답 입력을 **마이크**로 둔다("네"/"아니요"도 음성으로).
- 사자성어는 고른 뒤 한자 풀이를 적어도 10초 보여 주고 저절로 다음 문제로 넘어간다. 유래 읽기까지 보이려면 유래가 있는 문제(약 5문제 중 1문제)가 나올 때까지 **다음 문제**로 넘긴다.
- 중간에 그만두려면 **일시정지 → 게임 끝내기**(정차 중에는 게임 목록 머리 줄 — 게임을 열었으면 **← 목록**으로 나와서). 맞힌 문제가 있으면 "여기까지 했어요" 요약, 없으면 바로 홈.

## 3. 편집 가이드

- **길이**: 약 3분(§1 표의 누적 시간). 기다리는 구간은 자르거나 2~4배속(배속 구간은 소리를 끈다). 앱 TTS 가 나오는 구간은 1배속으로 둔다.
- **화면**: 녹화는 2560×1440 — 1920×1080 으로 내보낸다. 왼쪽 Driving view(계기판의 **P R N D**)는 기어가 바뀌는 근거라 자르지 않는다.
- **디버그 패널**이 보이는 구간(시뮬 설정·TBT 버튼·남은 5분으로·2단계 시험)은 잘라 낸다. 대신 시뮬 여정·대본 응답을 썼다는 것은 S4~S9 의 고정 자막으로 밝힌다.
- **SDK 라벨**: 장면마다 오른쪽 위에 작은 라벨(예: `NaviHelper · requestRoute`, `Vehicle · 기어/주행 규제`, `TTS · STT`) — §1 표의 "심사 포인트" 칸.
- **로그 창(선택)**: S4(기어 D → `ModeArbiter: PARKED+DO → VOICE`)·S5(`TBT … → 자동 일시정지`)·S7(`Drowsiness: Stage1/Stage2`)에서 logcat 을 옆에 잠깐 붙이면 "SDK 이벤트 → 동작"이 보인다.
- **파일 형식**: 에뮬레이터 녹화는 webm(VP9 + Vorbis). 편집기가 webm 을 못 읽으면 mp4 로 바꾼다(예: `ffmpeg -i clip.webm -c:v libx264 -crf 18 -c:a aac clip.mp4` — 이 PC 에서는 시험하지 않았다).

## 4. 녹화 전 체크리스트
- [ ] AVD cold boot, `adb devices` 에 emulator 표시
- [ ] `adb forward tcp:8088 tcp:8088` 후 Virtual Console 접속, 기어 P
- [ ] 권한 2개 허용(차량 속도·차량 위치)
- [ ] 시스템 볼륨이 켜져 있는지(Pleos TTS 음성이 영상에 들어가야 함)
- [ ] 주간 테마인지(`adb shell cmd uimode night` → `Night mode: no`), 창이 **앱 영역 전체**인지(3분할이면 클립 B 가 달라짐), 하단 독에 놀레오 아이콘(차콜 바탕에 노란 언덕 길과 웃는 해)이 하나만 보이는지
- [ ] 클립마다 [클립별 설정](#클립별-설정)의 데모 모드·여정·시뮬 경로·응답 입력·홈 선택 — 특히 클립 E 는 **출발 전에** 대본 sleepy·혼자·쉬지 않고·기준값 초기화, 그 뒤 클립에서는 **대본 normal** 로 되돌린다
- [ ] 이전 세션이 남아 있으면 홈의 "새로 시작". 클립마다 새로 출발(시뮬 남은 시간·대본 순서가 처음부터)
- [ ] 클립 A·B 전에 순정 내비에 길 안내가 없는지(있으면 홈이 `현재 경로`로 바뀌고 최근 목적지가 숨겨짐), 클립 B 뒤에는 내비에서 **안내 종료**
- [ ] 홈 목적지 맨 위가 시뮬 클립(C~H)에서는 시뮬 경로(`서울 → 부산` 또는 `서울 → 전주` · 시뮬 여정)이고 선택돼 있는지
