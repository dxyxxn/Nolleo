## 문서 관리
- 작업을 마칠 때마다(동작·화면 문구·자료·빌드가 바뀌었거나 사용자 결정이 있었으면) 위 문서 중 관련된 것을 같은 작업 안에서 고친다. 어떤 변경을 어느 파일에 적는지는 저장소 루트 [`../CLAUDE.md`](../CLAUDE.md) 의 "Keep the md docs in sync" 표를 따른다.
- 작업 현황은 날짜별로 새 파일을 만들지 않고 `WORK_STATUS.md` 하나를 갱신한다(사용자도 함께 고치므로 고치기 직전에 다시 읽는다).
- 확인한 것만 적고, 확인하지 못한 것은 이유와 함께 "확인 못 함"으로 적는다. 숫자·이름(문항 수·테스트 수·시간 등)은 문서끼리 맞춘다.
