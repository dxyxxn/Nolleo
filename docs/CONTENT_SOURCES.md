# 콘텐츠 출처와 생성 방식

모든 게임 콘텐츠는 앱에 포함된 `app/src/main/assets/` 파일이며, 실행 중 네트워크로 받지 않는다.

| 파일 | 내용 | 규모 |
|---|---|---|
| `content/quiz_regions.json` | 17개 시/도 지역 퀴즈 (특산물·지명·문화·음식) | 시/도별 10문제 (난이도 1:2:3 = 4:4:2), 총 170 |
| `content/quiz_general.json` | 지역 무관 가족 퀴즈 (동물·과학·자연·속담·음식·생활·문화) | 48 (난이도 18:20:10) |
| `content/chosung_quiz.json` | 정차 중 초성 퀴즈 낱말 + 힌트 | 40 (2음절 18 · 3음절 14 · 4음절 8) |
| `content/words_ko.txt` | 끝말잇기 사전 (2음절 이상 일반 명사) | 3,582 낱말, 첫 음절 611종 |
| `content/regions.json` | 17개 시/도 바운딩 박스·중심점·인접 지역·주소 키워드 | 17 |
| `demo/answers_normal.json`, `demo/answers_sleepy.json` | 시연·테스트용 대본 응답 | 각 10 / 8 항목 |

## 생성 방식

### 퀴즈 (지역·일반·초성)
- Claude(AI)가 작성 지침에 따라 직접 작성했다. 외부 문제집이나 웹 콘텐츠를 복사하지 않았다.
- 지침: 사실이 널리 알려지고 확인 가능한 것만(지리적표시 특산물, 유네스코 등 유명 문화유산, 오래된 축제, 대표 향토 음식), 전 연령, 존댓말·아이도 알아듣는 말투, 문제는 2문장 이내·문장당 80자 이하, 정답은 STT 가 잘 받는 짧은 명사, 난이도 1은 보기 두 개를 문제 안에 넣는 양자택일.
- 제외: 정치·역사 해석 논쟁, 지역 비하, 술·담배·도박, 재난·사고, 독도 등 분쟁 소재, 노래 가사(저작권).
- "처음 생겼다고 알려진"(인천 짜장면·쫄면)처럼 통설인 항목은 문장에 "알려진"을 넣었다.
- 검증: Node 스크립트로 스키마·문장 길이·힌트에 정답 노출 여부·양자택일 보기 포함·중복을 검사했고, 오답 보기가 퍼지 매처(포함·편집거리 1)에 잘못 걸리지 않는지도 확인했다. 앱 저장소의 `ContentAssetsTest` 가 같은 규칙을 단위 테스트로 다시 검사한다.
- 사람 검수: 개발 중 170개 지역 문항을 한 번 훑어 사실 관계를 확인했다. **2차 전 팀원 1명이 전체를 다시 검수할 것을 권장**한다.
- 알려진 주의점: `gyeonggi-02`(이천 → 쌀)는 정답이 한 글자라 STT 가 "살"로 들을 수 있다(허용 표기 "이천쌀" 포함).

### 끝말잇기 사전
- Claude(AI)가 범주별(동물·식물·음식·생활용품·학교·놀이·탈것·장소·직업·가족·자연·몸·추상 명사 등)로 생성했다. 외부 단어 목록·인터넷 자료는 쓰지 않았다.
- Node 스크립트로 병합 → 한글 2음절 이상만 남김(`/^[가-힣]{2,}$/`) → 중복 제거 → 금칙어(폭력·죽음·범죄·술·담배·도박·성인·비하 등, 짧은 낱말은 완전 일치로 오탐 방지) 제거 → 가나다순 정렬.
- 원시 4,910개 중 한 글자·기호 205개, 중복 824개, 금칙어·고유명사·신조어 287개를 걸러 3,582개가 남았다.
- 끝 음절 상위 30개에 대해 그 음절(또는 두음법칙 변환 음절)로 시작하는 낱말 수를 점검했다. "름·션·섯" 처럼 이을 말이 거의 없는 음절이 있어, 앱은 자기 차례에 막다른 음절로 끝나는 낱말을 피한다.
- 사전에 없는 낱말은 "다시 한번 말해 줄래요?" 후 관대하게 인정한다(가족 게임). 일부 합성어(예: 주행거리, 식기세척기)는 표준국어대사전 표제어가 아닐 수 있다.

### 지역 판정 테이블
- 17개 시/도의 대략적인 위경도 범위와 시청·도청 부근 중심점을 직접 정리했다(정밀 행정 경계 아님). 광역시·특별시는 반경(km)을 함께 둬 주변 도와 겹칠 때 구분한다. `RegionResolverTest` 로 주요 도시 좌표 판정을 확인한다.

### 시연 대본
- 직접 작성. `{correct}`·`{wrong}` 토큰으로 현재 문제의 정답/오답을 넣어 콘텐츠와 분리했다. sleepy 대본은 `driverOnly` — 운전자 차례에만 지연이 늘고 동승자는 평소 속도로 답한다.
